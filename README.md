# 🎬 Movie Recommendation System

A simple **Content-Based Movie Recommendation System** built using **Python** and **Streamlit**. Enter the name of a movie, and the application recommends **5 similar movies** based on their content.

## 🚀 Features

* 🔍 Search for a movie by its title
* 🎯 Get 5 similar movie recommendations instantly
* ⚡ Fast and simple user interface using Streamlit
* 📊 Content-based recommendation approach



## 💡 How It Works

1. Enter the name of a movie.
2. The system searches for the selected movie.
3. It compares the movie with all others using a precomputed similarity matrix.
4. The top **5 most similar movies** are displayed as recommendations.
